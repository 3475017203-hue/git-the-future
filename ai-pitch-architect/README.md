# 🎯 AI创新路演助手 (AI Pitch Architect)

> 基于 **中国国际大学生创新大赛** 金奖项目灵感实现的智能路演辅助工具
> 灵感来源：2024年创新大赛金奖项目"妙聊"路演展示模块架构

---

## ✨ 功能亮点

- **📝 智能路演脚本生成** — 输入项目信息，AI一键生成完整演讲稿
- **🎤 10页标准路演PPT内容** — 封面→痛点→方案→技术→市场→商业→竞品→团队→进展→融资
- **💡 AI逐页优化** — 可对任意幻灯片内容进行深度优化
- **📄 脚本导出一键下载** — 生成.txt格式路演脚本，方便打印练习
- **📋 历史记录管理** — 自动保存所有生成的路演，可随时查看和复用

本项目受以下获奖项目架构启发：

- **"法信AI" 智能法律咨询平台** — 2024年银奖，RAG增强内容生成架构

核心创新：**AI + 路演场景 + 标准Pitch Frameworks（电梯演讲→完整路演）**

## 🚀 快速启动

### 1. 安装依赖

```bash
cd /mnt/d/mycode/ai-pitch-architect
pip install -r requirements.txt
```

### 2. 配置AI API（推荐配置，效果更好）

**方案一：硅基流动（推荐，免费额度）**
```bash
export SILICONFLOW_API_KEY=your_key_here
```

**方案二：DeepSeek**
```bash
export DEEPSEEK_API_KEY=your_key_here
```

**方案三：OpenAI**
```bash
export OPENAI_API_KEY=your_key_here
```

### 3. 运行

```bash
python app.py
```

然后访问：**http://localhost:5095**

## 📖 使用流程

### Step 1：填写项目信息
在表单中填写：
- 项目名称
- 所属行业（AI/教育/医疗/电商/新能源...）
- 项目阶段（概念/原型/已有产品/已盈利）
- 核心痛点（一句话描述）
- 解决方案、核心技术、市场分析等

### Step 2：AI生成路演内容
点击「生成路演」，AI自动：
- 生成10页标准路演内容
- 撰写每页演讲稿
- 给出视觉建议

### Step 3：预览和优化
- 查看生成的幻灯片内容
- 可对任意页面进行AI二次优化
- 一键导出路演脚本.txt

### Step 4：练习演讲
- 打印导出的脚本
- 按页面练习演讲
- 控制每页60-90秒

## 📂 标准路演框架（10页）

| 页码 | 标题 | 时间 | 核心问题 |
|------|------|------|---------|
| 1 | 封面 | 5秒 | 你是谁？项目叫什么？ |
| 2 | 痛点分析 | 60秒 | 市场有什么问题？ |
| 3 | 解决方案 | 90秒 | 你怎么解决这个问题？ |
| 4 | 核心技术 | 60秒 | 你的技术有何优势？ |
| 5 | 市场分析 | 60秒 | 蛋糕有多大？ |
| 6 | 商业模式 | 60秒 | 你如何赚钱？ |
| 7 | 竞争优势 | 60秒 | 为什么你能赢？ |
| 8 | 团队介绍 | 60秒 | 谁来做这件事？ |
| 9 | 当前进展 | 60秒 | 你们做到了什么？ |
| 10 | 融资计划 | 60秒 | 你需要什么？ |

**总计：约10分钟（标准路演时长）**
